# Prior art: existing fixes for the car death glitch (checked 2026-11-01)

| | Car Physics Death Bug Fix (opt33) | Physics damage disabler (LarannKiar) | **Grav Lock** |
|---|---|---|---|
| Link | nexusmods.com/fallout4/mods/46566 | nexusmods.com/fallout4/mods/73724 | |
| Approach | Lowers physics damage (game settings) | Turns off the physics damage system | Stops the car from moving at all unless forced |
| Stops the car moving / rattling | No | No | **Yes** |
| Can the glitch still hurt you? | Yes, ~30-60 HP | No | **No: the car can't touch you** |
| Cars still explode and get thrown | Yes | Yes | **Yes** |
| Other physics damage (falling objects etc.) | Reduced | Disabled everywhere | **Unchanged** |
| Needs F4SE | No | Yes | **No** |
| Xbox | Possibly | No | **Yes (via Creations)** |

Notes:
- opt33's mod page: "if it occurs, it will only wound you about 30-60 health points." Doesn't affect exploding-car
  damage.
- LarannKiar: "disables the game's physics damage system. Requires F4SE." Toggleable by console command.
- A 2016 Nexus forum thread proposed making cars fully static; fully static cars can't explode and fly properly,
  which Grav Lock keeps.
- Other car mods (lootable cars, Looted World Expansion) don't target the glitch.

Use this for the mod page's "Why this mod?" section. Re-check before release in case something new appeared.
